# ودجات تيك توك لايف لبرنامج OBS

أدوات شخصية تربط حساب تيك توك المباشر (TikTok LIVE) ببرنامج OBS، وتعرض
لحظياً: الهدايا، المتابعات الجديدة، المشاركات، الإعجابات، الاشتراكات،
التعليقات، وعدد المشاهدين + آخر من انضم للبث.

## المتطلبات
- [Node.js](https://nodejs.org) نسخة 18 أو أحدث (منصب على جهازك).
- اتصال بالإنترنت.
- حساب تيك توك يبث مباشر وقت الاستخدام (البث لازم يكون شغال فعلياً).

## خطوات التشغيل

1. فك ضغط المجلد، وافتح الطرفية (Terminal / cmd) داخل مجلد المشروع.
2. ثبّت المكتبات المطلوبة:
   ```
   npm install
   ```
3. شغّل السيرفر:
   ```
   npm start
   ```
4. افتح المتصفح على:
   ```
   http://localhost:3000
   ```
5. من الصفحة، اكتب اسم حسابك في تيك توك (بدون @) واضغط "اتصال"
   — تأكد إنك تكون مباشر فعلياً في نفس اللحظة.
6. انسخ رابط أي ودجت تبيه (كل الأحداث / التعليقات / المشاهدين).

## إضافته في OBS

1. من قسم **Sources** اضغط **+** ثم اختر **Browser**.
2. الصق الرابط اللي نسخته من لوحة التحكم.
3. حدد العرض والارتفاع المناسبين (مثلاً 420 × 640).
4. تأكد إن خيار **"Shutdown source when not visible"** غير مفعّل، عشان
   الودجت يستمر يستقبل الأحداث حتى لو كان مخفي مؤقتاً.
5. خلفية الودجت شفافة تلقائياً، فبتنسدل فوق أي مشهد بدون صندوق حولها.

## ملاحظات مهمة

- **قائمة المشاهدين**: تيك توك ما يوفر (عبر أي أداة، حتى غير الرسمية)
  قائمة كاملة بكل من يشاهد البث لحظة بلحظة — بس يرسل إشعار كل ما شخص
  جديد ينضم. ودجت "المشاهدين" يعرض العدد الحالي + قائمة بآخر من انضم،
  وهذا أقصى شي ممكن تقنياً.
- إذا انقطع البث أو أعدت تشغيله، اضغط "اتصال" مرة ثانية من لوحة التحكم
  بنفس اسم الحساب.
- المشروع يستخدم مكتبة غير رسمية (`tiktok-live-connector`) للاتصال
  ببيانات البث المباشر لأن تيك توك ما يوفر API رسمي عام لهذا الغرض.
  أحياناً تيك توك يغيّر أشياء داخلية فتتوقف المكتبة عن العمل مؤقتاً؛
  في هذي الحالة تحقق من وجود تحديث للمكتبة:
  ```
  npm install tiktok-live-connector@latest
  ```
- كل شي يشتغل محلياً على جهازك فقط (localhost) — ما فيه أي بيانات
  تروح لأي سيرفر خارجي غير تيك توك نفسه.
